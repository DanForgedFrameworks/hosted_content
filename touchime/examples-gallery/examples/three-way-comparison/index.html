Each panel uses the same three headings, so the approaches can be read side by side. Select a panel, or press Tab to reach it. The panel opens and its detail appears. Press Escape to close the one you opened.

Tissue sample

Select to compare

What it offersTissue is the standard sample. It confirms the type of lung cancer, can be used to test for other markers and shows changes such as transformation to small cell.

When to use itA broad panel is preferred. It tests EGFR and other targetable genes at the same time, which saves tissue and time.

What it can missBiopsies are often small, and a repeat biopsy adds risk and delay.

Blood test (ctDNA)

Select to compare

What it offersA blood test looks for tumor DNA in the bloodstream (ctDNA).

When to use itIt is useful when tissue is limited or a biopsy is not possible, or alongside tissue to speed up results.

What it can missA ctDNA test is less reliable for gene fusions and copy number changes, and cannot assess PD-L1 or tissue type.

When to use itResults needed fast

What it can missPCR finds only the mutations it is designed to detect. In real-world data, about half of exon 20 insertions found by sequencing would have been missed by PCR.
